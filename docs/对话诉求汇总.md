## 一、五个阶段

### 阶段 1 · 立风格：先把图标和鲸鱼画对（10-19 01:30–04:31 · A）

起点很克制：先建工作区、先出动画文件，**确认之后再动插件**。这一段的输入几乎全是像素级的
视觉校准——虚线怎么断、遮挡留哪一层、喷水几根线、水珠放哪儿。

关键诉求：
- 风格贴官方 UI，以已有的"线条风格蓝色虎鲸"为基准；
- 余额三态（粮仓 / 满碗 / 空碗），仓库要抽象成竹席 + 茅草顶；
- 鲸鱼条四段状态（静止 / 思考 / 工作 / 捕食），靠海面后退体现速度、捕食前跃后归位；
- 遮挡只留最前一层浪，且被挡住的部分要真的隐藏；
- 每改一步存一个小版本，方便对照（v1 → v3.13 → v4）。

结果：v4 定稿 + 迭代过程文件 + 三段总结（需求汇总 / 工作记录 / 经验）。

### 阶段 2 · 进插件：从动画到真功能（10-19 18:34–10-23 18:24 · A）

从"网页演示"进到"插件本体"，这一段的重心从美术转到工程：位置、实时数据、诊断。

关键诉求：
- 三个位置先说清楚（余额在头像行、鲸鱼在输入框下沿、统计右对齐）；
- 余额必须取真实账户数据，点击时实时取，不是硬编码；
- 粮仓要和头像同一行，别被更新按钮挤走；
- 设置项要真的能用（预警阈值、鲸鱼缩放、口径切换），且重启后保留；
- 今日消耗 = 各对话累计，不是当前对话；峰谷要分别计；
- 出问题先贴诊断报告定位，再改。

### 阶段 3 · 交出去测：修 bug 与做宣传片（11-03 18:12–11-06 13:33 · B）

换了个会话重新测插件，"发现问题先找我确认再改"是这段的规矩。后半段转为创作：
先要填色版鲸鱼，再要宣传片。

关键诉求：
- 消耗面板先弹空壳再出数字，要一次到位；悬停拆解层级不能错；
- 新增"填色"风格（蓝白 / 黑白），与线稿在设置里切换，腹部与眼睛按官方 logo 留白；
- 宣传片：贴官方风格 → 允许自由发挥 → 加节拍对齐 BGM → Pad 嗡声太大，出减弱/去掉两版；
- 第二版宣传片要"更贴官方"、体现"工作之余有消遣"、**避免办公室尴尬**；
- 背景改浅色；同步输出每个分镜的详细说明。

### 阶段 4 · 定时发送：独立做，最后并入（11-06 17:02–22:54 · C）

一个独立插件：输入框旁加沙漏，定好时分再发送。技术上不难，难在"等待中的消息长什么样"——
这一段的 32 条输入里有 12 条在调同一张卡片的形状。

关键诉求：
- 沙漏点开设定时、分，到点才发出；
- 等待卡片要"吸附"在输入框上沿，不能是浮在旁边的独立矩形；
- 插话发送时，等待卡要压在下面并跟随移动；
- 卡片弹出不能顶动对话布局；
- 收尾并入 `dsh-plugin-whale`，不单独存在。

### 阶段 5 · 新功能：消遣模式与沙漏（11-08 03:13–18:52 · D + C 尾）

给 whale 加"玩"的部分，以及把定时发送的图标换成会漏沙的沙漏。

关键诉求：
- 零食向右缓慢漂，吃动画复用工作结束那一下跳跃，只有落下接触才算吃到；
- 统计分两类：米饭（消耗图标）与小鱼（新画鱼刺图标），运行中显示本轮、否则显示历史最高；
- 开关精简成一枚鲸鱼图标：未开启线稿、开启后从头部开始染蓝；
- 沙漏整体改蓝、结束后翻转、翻转后沙子自下而上填满；
- 等待区消息可点击时间改期、双击撤回重新编辑；
- 喷水效果不好，先关掉。

## 三、从这些输入里能看出什么

**1. 先原型，后插件。**
几乎每个功能都是"先给我一个 HTML 演示 / 原型，我确认再看插件里"（10-19 18:34、
11-08 03:29）。插件安装、重启、找 DOM 的成本高，原型确认的成本低。

**2. 给参数，不给形容词。**
"圈足放大到碗沿 1/3–1/2""间距减 10%""红点缩到 1/4""上边缘保持、下边缘再降一个字高"——
能说数字就不说"大一点"。这既是要求，也是在帮我收敛。

**3. 参考图优先，但不要求复刻。**
